- Implemented control algorithms using IEC 61131-3 Structured Text.

- Designed a WebVisu operator interface.

### 2. Heat Exchanger Temperature Control – MATLAB Simulation (2026)

Modelled a heat exchanger with transport delay and evaluated conventional PI control against a Smith Predictor-based control strategy.

- Developed a First-Order Plus Dead Time (FOPDT) process model.
- Performed system identification using a noisy step-response test.
- Applied SIMC-based PI controller tuning.
- Evaluated controller performance under disturbances, parameter mismatch and measurement noise.

**Tools:** MATLAB, Control System Toolbox, System Identification Toolbox

[View Project Repository](https://github.com/anjanamahi011/Heat-Exchanger-Smith-Predictor-matlab)

### 3. FBG-Based Water Level Detection System (2025–2026)

Developed and experimentally evaluated a Fiber Bragg Grating (FBG)-based optical sensing system for water-level detection.

- Investigated the wavelength response of two vertically positioned FBG sensors.
- Evaluated sensor sensitivity during water-level variations.
- Observed an experimental sensitivity of approximately 7 pm/cm.
- Analysed temperature cross-sensitivity and baseline drift.

**Technologies:** Fiber Bragg Grating Sensors, Optical Interrogator, Optical Measurement

[View Project Repository](https://github.com/anjanamahi011/FBG-Based-Water-Level-Detection)

### 4. Automatic Fault Detection and Location in Distribution Lines (2023)

Developed a sensor-based monitoring system for fault detection and localization in electrical distribution lines.

- Implemented sensor-based fault monitoring and automated decision logic.
- Integrated sensing and communication modules for continuous monitoring.
- Evaluated the system through project development and testing.

**Technologies:** Microcontrollers, Sensors, Electrical Systems, IoT
